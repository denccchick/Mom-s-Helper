# Mom's Helper

Десктоп-приложение для перевода и конвертации документов (DOCX, PDF) с использованием моделей машинного обучения, обученных на реальных данных. 
Всё работает локально на вашем компьютере — никаких облачных сервисов, никакой отправки данных в интернет.
Данное приложение предполагает использование в условиях, где важна конфиденциальность данных и возможность работы локально на офисных компьютерах без GPU .
В данном случае модель для перевода обучена на данных технического домена.

---

## Что умеет

- **Перевод DOCX** с английского на русский с сохранением форматирования (жирный, курсив, таблицы)
- **Конвертация PDF → DOCX** и **DOCX → PDF**
- **OCR** для сканированных PDF (распознаёт текст на картинках)
- **Предпросмотр** в реальном времени (показывает, что переводится прямо сейчас)
- **Три режима качества** (быстро, сбалансированно, максимально точно)
- **Работает без интернета** — все модели уже внутри сборки

## Использование

На данный момент установочный файл (setup) не включён в репозиторий, чтобы избежать утечки данных через модель. 
В одном из следующих релизов возможно добавление обезличенной версии модели и конфигурационных файлов для быстрого развёртывания, а также инструкций для самостоятельного запуска.

## Обучение модели

Модель обучена на реальных документах из профессиональной практики переводчика. Данные были:

- извлечены из парных PDF/DOCX
- очищены с помощью Qwen 2.5-7B (локально) 
- семантически выровнены по смыслу
- дообучены с помощью LoRA на NLLB-600M

После обучения модель сжата в формат CTranslate2 с квантизацией int8, что позволяет ей работать на обычном CPU (без видеокарты) с низким потреблением памяти (~600 МБ на диске, ~500 МБ в оперативной памяти).

## Требования к оборудованию

- Процессор: любой процессор архитектуры x86, достаточно 4 ядер
- Оперативная память: от 4 ГБ
- Диск: около 2 ГБ свободного места (вместе с моделью)
- Видеокарта не требуется
